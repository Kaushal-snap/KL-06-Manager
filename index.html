V0.4.2-BETA MOBILE ARCHITECTURE

Restructured Navigation Priorities

KL-06 Manager reorganizes mobile controls around real-world workflows: instant wireless file sharing first, direct on-device hardware controls second, and desktop telemetry consolidated cleanly into Etc.

1st Priority Default Landing
📁

File Sharing (AirDrop / Quick Share)

Instant wireless peer-to-peer file drop. Lands directly on radar discovery when opening the mobile app for immediate transfers.

  • 📡 Real-time UDP & TLS port 8766 radar scanning
  • 🚀 High-speed chunked LAN streaming with SHA-256
  • 📂 WebChromeClient file chooser & document picker
  • 🔄 Active transfer queue with pause & auto-retry
2nd Priority On-Device Tools
📱

Inbuilt Mobile Controls

Immediate tactile control over your phone or tablet's local hardware without digging through deep operating system settings.

  • 🔊 Direct in-app media volume scalar slider
  • ☀️ Window & screen brightness tuning slider
  • ☕ Bounded Keep-Awake toggle for large transfers
  • 🔋 Live battery percentage & power telemetry
  • 💾 Scoped MediaStore auto-save to Download/KL-06/logs
3rd Priority Consolidated
⚙️

"Etc" PC & Mac Companion

Desktop and laptop features are cleanly organized into a dedicated "Etc" menu, keeping the mobile interface lightweight and responsive.

  • 🌪️ Safe read-only Mac & Windows fan RPM monitor
  • 📈 HWiNFO sensor CSV history parser & canvas graph
  • 🎛️ Reversible Dock, Finder, and system tweaks
  • 💻 Remote PC lock, sleep, and master volume control
4th Priority Verified Safety
🛡️

Safety, Invariants & Privacy

Zero compromise on system stability and user privacy. Strict cryptographic verification and sandboxed local execution.

  • 🔒 Mutual 6-digit PIN pairing with 60s monotonic window
  • 🔕 100% offline local network (zero cloud telemetry)
  • 🛡️ 20 declared permissions; no mic, camera, or broad storage
  • 📦 Dual APK Signature Scheme v1 (JAR) + v2 signed

POWERFUL CAPABILITIES

Built for Performance, Speed & Privacy

Everything you need to orchestrate your Hackintosh laptop, PC, and mobile companion effortlessly.

🔄

Universal AirDrop / Quick Share

Seamless two-way chunked file transfer between Android and macOS, Windows, and iPhone. Streamed with SHA-256 chunk validation.

🔒

6-Digit PIN Authentication

Devices never connect silently without consent. Generates a cryptographically strong 6-digit PIN with monotonic 60s expiration.

📱

Single-Page Mobile Dashboard

All phone telemetry, live radar waves, hardware switches (brightness, volume, keep-awake), and laptop controls unified on one screen.

⌨️

Global F13 Hotkey Support

Map Print Screen (PrtSc) key directly to macOS F13 with zero lag to instantly summon or dismiss the companion window.

🔆

OLED & DPCD Brightness Control

Native Intel Iris Xe OLED brightness slider without modifying system kexts or breaking WhateverXe 0.8.2 graphics acceleration.

🛡️

Non-Invasive Safety Architecture

Zero SMC/EC writes, zero persistent pmset changes, strict allowlisted IPC endpoints, and offline local network operation.
