# Mac architecture — beta.2 / build 5

AppKit hosts a bundled offline WKWebView with a non-persistent data store and restrictive CSP. Native bridge accepts only known operations/strict fields from the exact bundled **main-frame** index file; no arbitrary command/path/URL/SMC-write method. `Core.swift` holds current native counters, 12-key preference journal, Core Audio readback and the existing fixed optional power sample. `HotKey.swift` preserves the running-only unmodified F13/105 Carbon registration/window policy.

`SMCReader.c/.h`: independently authored bounded legacy read frame with explicit offsets, fixed `FNum`, `F0Ac`, `F1Ac` only and read-info/read-value commands. No EC scan/key enumeration/vendor probe/driver install. C report imported by an explicit bridging header, not a Swift guess at ABI frame layout. Decoder validates types/lengths/ranges; invalid/unavailable RPM is null, not zero.

`FanMonitor.swift`: one utility worker, no overlap, ≥5-second polling, ≤2 fans, query-result completion time/age, stale after 12 seconds using wall + monotonic age (ordinary sleep included through wall age). No hard cancellation of a stuck kernel call; the cached reading expires and further work is not queued behind it. Physical acquisition time/calibration is unknown. Native CPU uses measured tick deltas and resets after a long gap; graph gaps stay gaps. Snapshot cache is one second. When hidden **and companion off**, native counter sampling is skipped. Opt-in companion sessions explicitly permit low-rate background snapshots.

`Resources/history.js`: pure bounded numeric CSV projection, source-separated stats/timestamped history, shared byte-identically with common Windows/mobile assets. Native picker accepts one regular bounded 5 MiB UTF-8/cp1252 file; no JS file-path argument. Parsed identity/source free text is discarded; history is transient window memory, not snapshot export/LAN data or a hardware-control capability. Timestamp format does not certify the original recording's clock/timezone.

`DesktopCompanion.swift` + sibling `../companion/server.py`: optional current-user, private-IPv4 TLS session only. Native host generates an ephemeral local certificate, launches installed Python in isolated mode with only the bundled fixed broker, shares private capped IPC snapshots/requests, owns pair/write confirmations and executes only the same local allowlist. Matching explicit mach uptime deadlines plus UTC rechecks bound pair/command life despite clock rollback. Every write shows actual value/title/ID and checks pending-file existence/process/expiry again after confirmation. No phone can invoke the optional power authorization or an arbitrary shell. No code/token is returned to JS/report. `../docs/COMPANION-PROTOCOL.md` specifies limits/races/crash handling.

Builder requires the whole source root, compiles C/Swift for Intel macOS 13+, copies only named resources/project license/broker, ad-hoc signs/verifies and reveals a **new** app; no auto-launch/install/replace. `KL06_REVEAL_BUILD=0` only suppresses Finder reveal for owner-enabled CI. Native tests inject fake preference backends and synthetic C transport; this export has **not** been compiled with Apple SDKs.

No signed root helper, kernel extension, cloud agent/updater, login item or firmware/EFI/partition change. Proper future privilege separation would be a separately approved signed-helper/removal design, never a custom password box/security bypass.
