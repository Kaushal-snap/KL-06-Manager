# Targeted fan evidence, not another generic inventory

Existing owner hardware reports are already reviewed and kept privately outside app source. This beta includes only `COLLECT-MAC-FANS.command` for the missing native SMC fan-provider result. See README and OWNER-TEST-CHECKLIST. HWiNFO Windows history can be imported locally; it cannot enable a Mac provider. No report auto-upload, firmware probing or driver install occurs.
